## 一句话介绍

马卡龙配色、大圆角卡片、自带动画效果的 HTML 幻灯片，说一句话就出整套。

## 技能简介

这是张世鑫自研的演示文稿技能。它不做呆板的商务 PPT，而是生成活泼可爱的「糖果风」HTML 幻灯片：马卡龙多彩配色、大圆角卡片、柔和阴影、浮动装饰元素，页面自带弹跳入场和悬停动画——浏览器直接打开就能演示，特别适合内部培训、团队分享、课程课件。

## 核心能力

- 马卡龙多彩配色，大圆角卡片版式
- 弹跳入场、悬停交互、彩虹进度条等动画
- 星星、云朵、气泡等浮动装饰元素
- 输出单个 HTML 文件，双击即可演示
- 培训课件、产品介绍、活动方案都适用

## 使用流程

1. 告诉它演示主题和大纲
2. 它生成整套糖果风幻灯片
3. 浏览器打开，方向键翻页
4. 不满意就说哪页要改，单独调整
