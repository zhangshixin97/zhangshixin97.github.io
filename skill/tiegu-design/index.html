公众号贴图设计使用说明。

## 一句话介绍

把一篇文章、一份干货、一个知识点，做成一整套 8 张公众号/小红书贴图 + 千字正文。

## 技能简介

这是张世鑫自行打磨的公众号贴图设计技能。它按一套固定骨架，把任何想讲透的内容做成 8 张 3:4 竖版贴图（封面钩子 → 痛点 → 认知翻转 → 方法拆解 → 上手节奏 → 灵魂拷问尾卡），并配一段 800-1000 字正文——封面抓点击，尾卡用「评论引导」换互动，适合用于实操经验分享和后续复盘。内附张世鑫 VI 视觉系统（浅色蓝点风）和可复用的 HTML 模板。

## 核心能力

- 8 卡固定骨架：封面钩子 → 痛点 → 认知翻转 → 方法拆解（可 2-4 张）→ 上手节奏 → 灵魂拷问尾卡
- 张世鑫 VI 视觉系统：浅色蓝点风（#3B5BFD），MiSans + JetBrains Mono，蓝点签名
- 尾卡用「灵魂拷问 + 评论区聊聊」引导互动，不是普通点赞转发
- 正文纯文本输出，复制粘贴零删改
- 内附可复用 HTML 模板（内容占位符，换字不改骨，Chrome 无头一键出图）

## 使用流程

1. 定选题：这篇内容想讲透哪一个核心点
2. 按 8 卡骨架写文案（单卡≤150字、标题≤20字）
3. 套用 HTML 模板，Chrome 无头一键出 8 张图
4. 配正文、发布，拿到后台数据回填复盘
