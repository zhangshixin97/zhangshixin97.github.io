公众号排版设计系统的使用流程、获取方式与作者说明。

原作者：甲木（isjiamu），GitHub 开源：github.com/isjiamu/gzh-design-skill。本站收录分享。

## 一句话介绍

把 Markdown 文章一键排成公众号编辑器里能直接用的精美 HTML。

## 技能简介

这是公众号排版博主「甲木」开源的排版引擎，本站收录分享。它内置一整套主题组件库——每套主题都有设计好的标题、引言卡片、分割线、代码块、图片样式，把你的 Markdown（Word、PDF 也行）转成粘贴到公众号后台样式不丢的 HTML，还能按你的描述或参考图定制专属主题。

## 核心能力

- Markdown / Word / PDF / 纯文本输入，自动归一化
- 多套主题组件库任选，章节自动编号
- 引言卡片、目录导航、关键词标记自动生成
- 「一键自动排版」：自动推断结构、自选主题
- 按你的描述或参考图生成专属主题，保存复用

## 使用流程

1. 把文章发给它（或直接丢文件）
2. 选主题，或直接说「自动排版」
3. 拿到排好的 HTML
4. 粘贴进公众号编辑器，样式原样保留
