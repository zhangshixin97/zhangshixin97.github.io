## 技能简介

开源社区作品（MIT 协议），本站收录分享。它不走「模拟人工点编辑器」那条路，而是直接调公众号发布接口：Markdown 或 HTML 文件丢进去，几秒钟就出现在你的公众号草稿箱里，格式完整保留。适合有公众号、想批量或定时发稿的运营者。

## 核心能力

- Markdown 文章一键转成公众号草稿
- HTML 文件直接发布，排版原样保留
- 支持多公众号管理，想发哪个发哪个
- 支持图文、图片消息等多种类型

## 使用流程

1. 先在 wx.limyai.com 注册并授权你的公众号，拿到 API Key
2. 把写好的 Markdown 或 HTML 文章准备好
3. 告诉 AI 用哪个公众号发布
4. 草稿箱里确认效果，手动点群发
