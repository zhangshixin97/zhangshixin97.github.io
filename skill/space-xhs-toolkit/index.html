小红书起号十件套的使用流程、获取方式与作者说明。

原作者：SpaceZephyr，GitHub 开源：github.com/SpaceZephyr/creator-buddy。本站收录分享。

## 一句话介绍

定位、选题、标题、正文、封面、复盘——10 个 Skill 把小红书从 0 到 1 全链路包圆。

## 技能简介

这是 AI 创作者「SpaceZephyr」开源的小红书运营全家桶，本站收录分享。它把「运营一个小红书号」拆成定位、选题、写作、视觉、复盘五个环节，每个环节一到两个 Skill，再加一个总控路由把它们串起来——你说「帮我做小红书」，它先问清楚你卡在哪，再派对的 Skill 上场。

## 十件套清单

- 路由总控：space-xhs-buddy，一句话自动派活
- 账号定位：space-xhs-positioning，产出定位句、人设三件套、前 20 篇选题
- 选题：space-xhs-hotspot，抓领域热门笔记找选题
- 写作：space-xhs-title（标题）+ space-xhs-writer（正文）
- 视觉：space-xhs-cover（封面）+ space-xhs-image（生图）
- 复盘：space-xhs-account-audit（账号）+ space-xhs-note-analytics（单篇）
- 排版：xhs-html，笔记长文排成精美 HTML

## 使用流程

1. 全部安装后，直接说「帮我做小红书」
2. 总控先问你现在卡在哪个环节
3. 路由到对应 Skill，按顺序推进
4. 定位 → 选题 → 写作 → 视觉 → 复盘，一轮跑完
